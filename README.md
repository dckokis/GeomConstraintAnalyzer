Будем проводить анализ степней свободы системы опираясь на линеаризацию СНАУ в окресности точки x₀

Для этого необходимо построить матрицу Якоби, вычислив частные производные каждого уравнения по нефиксированным переменным.
Элементы матрицы формируются аддитивно, для корректной обработки переменных, участвующих в нескольких уравнениях.

Затем определим число степеней свободы как DOF = N - r, где N - число переменных в системе, r - ранг матрицы Якоби.

Ранг матрицы Якоби определим через QR разложение с выбором ведущего столбца. QR разложение будем искать с помощью метода отражений
(Метода Хаусхолдера), точность возьмем 10⁻⁹.

Основные шаги алгоритма:
1. К матрице Якоби применятся последовательность отражений Hₖ = I − τₖ vₖ vₖᵀ, где вектор vₖ строится так, чтобы обнулить поддиагональные элементы *k*-го столбца.
2. На каждом шаге среди оставшихся столбцов выбирается тот, норма поддиагональной части которого максимальна. Это гарантирует, что наиболее линейно независимые столбцы обрабатываются первыми.
3. После приведения к верхней треугольной форме ранг определяется как количество диагональных элементов Rᵢᵢ, превосходящих по модулю порог τ × maxᵢ|Rᵢᵢ|.
4. Если на некотором шаге норма оставшихся столбцов становится пренебрежимо малой, разложение досрочно завершается.

По соотношению ранга, DOF и числа уравнений M система получает один из статусов:
- **WellDefined:** r = M и DOF = 0.  
  Количество независимых уравнений равно числу неизвестных. Локально система имеет конечное множество решений.

- **UnderDefined:** r = M и DOF > 0.  
  Уравнений меньше, чем степеней свободы; существует непрерывное семейство решений.

- **OverDefined:** r < M и DOF = 0.  
  Часть уравнений является линейно зависимой (избыточной) в точке линеаризации. Удаление избыточных уравнений не изменяет DOF.

- **Unknown:** r < M и DOF > 0.  
  Одновременно присутствуют как избыточные уравнения, так и нехватка ограничений для фиксации решения. Линеаризованного анализа недостаточно для разделения этих эффектов.

Метод даёт достоверный ответ при выполнении следующих условий:
- Ранг матрицы Якоби постоянен в некоторой окрестности начального приближения x₀.
- Точка x₀ не является особой для рассматриваемых уравнений.
- Система не содержит противоречий, которые не проявляются в первых производных.

Типичные ситуации, приводящие к статусу Unknown:
- Начальное приближение находится вблизи особой точки, где производные обращаются в нуль или становятся линейно зависимыми.
- Система содержит одновременно избыточные и недостающие ограничения (например, часть уравнений дублируется, но всё ещё не хватает одного условия для фиксации всех степеней свободы).
- Сильная численная обусловленность, при которой допуск 10⁻⁹ не позволяет надёжно отделить значимые сингулярные числа от шума.
